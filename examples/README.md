# Synthetic examples

These JPEG/PNG images are newly generated geometric illustrations. They contain
no real horse, human, race, footage or private research. The example observations
mark all biological features unobservable with `null` descriptions/confidence.
They demonstrate storage and integrity checks, not AI accuracy.

All files in this directory are newly authored for this project and included in
the project's MIT proposal. The image hash is computed from the exact example
bytes. The timestamp/result ID in example JSON is a synthetic fixed example.

To regenerate the examples locally, run `python -B examples/create_examples.py`.
The script performs no network request and uses no external media or fonts.
